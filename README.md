# 🎯 Augustin's YouTube Focus Filter

A lightweight, zero-bloat uBlock Origin filter list designed to give you your attention back. 

This filter strips away YouTube's highly engineered recommendation algorithm, leaving you with a clean, distraction-free tool. You only see what you intentionally search for. 

## ✨ Features
* **No Homepage Feed:** The YouTube homepage is completely blank. 
* **No "Up Next" Sidebar:** Watch your video without the temptation of a dozen related videos.
* **No Shorts:** Completely removes the addictive Shorts shelves.
* **No End-Screen Popups:** Stops videos from suggesting new content in the final 10 seconds.
* **No Explore/Trending Tabs:** Removes algorithm-driven tabs from the navigation menu.
* **Search & Subscriptions Work Perfectly:** You can still search for videos and view your manual subscriptions feed.

## 🚀 Installation

You don't need to install any new, heavy browser extensions. If you use [uBlock Origin](https://ublockorigin.com/), you can add this filter in seconds.

### Option A: Subscribe via URL (Recommended)
This method allows your filter to automatically update if I make improvements to the code.
1. Open the **uBlock Origin Dashboard** (click the extension icon -> ⚙️ gear icon).
2. Go to the **Filter lists** tab.
3. Scroll to the very bottom and check **Import**.
4. Paste the raw URL of the filter text file:
   `https://raw.githubusercontent.com/iamaugustinthomas/Augustin-s-YouTube-Focus-Filter/main/augustins-youtube-focus.txt` *(Make sure to update this link with your actual GitHub repo details!)*
5. Click **Apply changes** at the top left.

### Option B: Manual Copy/Paste
1. Open the **uBlock Origin Dashboard**.
2. Go to the **My filters** tab.
3. Copy all the code from `augustins-youtube-focus.txt` and paste it into the text box.
4. Click **Apply changes**.
